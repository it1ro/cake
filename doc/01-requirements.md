# Requirements

## Цель

CLI-утилита `cake` для извлечения контекста из кодовой базы
для передачи в LLM (Claude, GPT, локальные модели).

На старте — Go-центричная, с архитектурным заделом под другие языки.

## Целевая аудитория

- Разработчики, которые вручную копируют файлы в чат LLM.
- AI-агенты (через stdout / MCP), которым нужен структурированный контекст.
- CI-скрипты для подготовки снапшотов кода.

## MVP Use Cases (v0.1)

### UC-1. Полный тегированный дамп проекта
- Обход директории с учётом `.gitignore`.
- Фильтры: include/exclude по glob, по расширению, по размеру.
- Определение языка файла.
- Вывод в XML-подобном формате с деревом проекта в начале.
- Опционально: копирование в буфер обмена (OSC 52).

### UC-2. Чистый дамп Go-файлов без комментариев
- Парсинг через `go/parser`.
- Удаление обычных и doc-комментариев (флаг `--keep-doc`).
- Сохранение валидности кода (не ломать build-теги, не удалять импорты).
- Единый стиль форматирования (`go/printer`, tabs, width=4 или 8).

### UC-3. TUI ручного выбора файлов
- Интерактивный выбор файлов и директорий.
- Fuzzy-поиск по путям.
- Live-оценка количества токенов для выбранного набора.
- Переключение режима вывода (dump / clean) прямо в TUI.
- Экспорт в stdout / файл / буфер обмена.

## Нефункциональные требования

- **Кроссплатформенность**: Linux, macOS, Windows.
- **Без CGo** в v0.x (важно для простой сборки и release-бинарей).
- **Производительность**: обход 50k файлов < 5 сек на SSD.
- **Стриминг**: не держать весь вывод в памяти.
- **Нулевая конфигурация**: работает из коробки в любом репо.
- **Бинарь < 15 MB** в stripped-сборке.

## Вне scope v0.x

- Tree-sitter / мультиязычный парсинг.
- MCP-сервер.
- AI-интеграции (прямые запросы к моделям).
- Векторные эмбеддинги.
- Watch-режим.

## Критерии готовности v0.1

- [ ] Три команды (`dump`, `clean`, `pick`) работают end-to-end.
- [ ] Покрытие тестами ключевых пакетов ≥ 60%.
- [ ] Бинарники собраны под linux/amd64, darwin/arm64, windows/amd64.
- [ ] README с примерами использования.
- [ ] Бенчмарк на репозитории kubernetes/kubernetes без падений.
